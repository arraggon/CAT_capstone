# CAT – Cellphone App-Controlled Toy

**Oregon State University | ECE Capstone Project | 2026–2027**

## Overview

CAT (Cellphone App-Controlled Toy) is a senior capstone project developed by a team of three Electrical and Computer Engineering students at Oregon State University.

Our goal is to design and build a spherical robotic toy that can be controlled wirelessly through a smartphone application. The robot is intended to provide an interactive experience for cats through movement and potentially sound.

The project combines embedded systems, wireless communication, mobile application development, PCB design, and mechanical engineering.

## Project Objectives

Our current design goals include:

- **Spherical Robot:** Develop a compact, enclosed robotic toy capable of moving across the floor.
- **Smartphone Control:** Allow users to control the robot through a mobile application.
- **Wireless Communication:** Establish a reliable wireless connection between the smartphone and robot.
- **Internal Motion System:** Investigate a pendulum-based mechanism that shifts the robot's center of gravity to produce movement.
- **Rechargeable Battery:** Power the robot using an internal rechargeable battery.
- **Wireless Charging:** Explore wireless charging to eliminate exposed charging ports.
- **Sound Interaction:** Investigate adding a speaker or other sound-generating component to increase interaction.
- **Custom PCBs:** Design and test student-developed PCBs for the robot's electronic subsystems.

These objectives represent our initial design direction and may change as development progresses.

## System Architecture

Our proposed system consists of several interconnected subsystems:

| Subsystem | Description |
|---|---|
| Mobile Application | Provides the user interface for controlling the robot |
| Wireless Communication | Transfers commands between the smartphone and microcontroller |
| Microcontroller (MCU) | Processes commands and coordinates robot operation |
| Motor Control | Controls the motors responsible for movement |
| Mechanical System | Converts internal movement into rolling motion |
| Power System | Provides battery power and charging functionality |
| Sound System | Provides optional audio interaction |

We are currently considering the **Arduino Uno R3** as our initial microcontroller platform. The final hardware configuration will be determined during the design and prototyping stages.
