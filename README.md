# CAT
### Cellphone App-Controlled Toy

**Oregon State University | ECE Capstone 2026–2027**

---

## About the Project

CAT is a senior capstone project developed by three Electrical and Computer Engineering students at Oregon State University.

Our goal is to design and build a **spherical robotic toy for cats**, controlled wirelessly through a smartphone application.

The project combines embedded systems, wireless communication, custom PCB design, mobile application development, and mechanical engineering.

## Key Features

- **Spherical Design** — Enclosed robotic toy with an internal movement mechanism.
- **Smartphone Control** — Wireless control through a mobile application.
- **Rechargeable Power** — Battery-powered design with potential wireless charging.
- **Interactive Features** — Exploration of sound-based interactions.
- **Custom Hardware** — Student-designed PCBs for electronic subsystems.
