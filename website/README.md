# CAT — Cellphone App-Controlled Toy

Oregon State University · ECE Capstone 2026–2027

A spherical robotic toy for cats, designed for wireless control through a smartphone application.

## Project website

This repository includes a static showcase website in `index.html` and `style.css`.

**Publish with GitHub Pages:** Open the repository's **Settings → Pages**, choose **Deploy from a branch**, select your default branch (`main`) and the root folder (`/`), then save. Your website will be available at `https://<username>.github.io/<repository>/` once deployed.
